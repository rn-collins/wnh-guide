# Women's Neuro-Health Evidence Navigator | WNH

A local-first evidence and appointment-preparation tool for neuro-health questions across life stages, cannabis, psychedelics, medications, and symptoms.

**Live:** https://wnh-guide.vercel.app

## Repository contents

`index.html`, `privacy.html`, `robots.txt`, `sitemap.xml`, `terms.html`, `vercel.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
